Linux Memory Kernel Subsystem

What this page reads

The kernel publishes a machine-wide account in /proc/meminfo: MemTotal, Cached, AnonPages, Slab, SwapTotal/SwapFree. This room draws those buckets as strips. It is not a profiler and not a second process list.

Page cache, anonymous memory, slab

File-backed pages sit in the page cache (Cached). Process heaps and stacks are anonymous (AnonPages). Kernel objects live in slab. The picture is the same split the kernel uses in mm/, not a guessed pie chart.

Task RSS

Beside the host account, sampled processes show resident set size from /proc/<pid>/status (VmRSS). That is how much RAM the task occupies now, not virtual size and not a lifetime sparkline.
